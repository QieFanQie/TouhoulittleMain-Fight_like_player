# TouhoulittleMain-Fight_like_player  
让车万女仆像人类一样打架的模组，接入了车万女仆的对话llm。我说会打的。  
代码全是AI写的。基本框架是我设计的。差不多就是这样。  
大致包括：  
1、可以让女仆切物品，用多种方式在一个模式下进攻。  
2、有一个能实现基础战斗策略（铁斩波）的雏形（我对它的能力没什么信心）。  
3、接入jev的决策层。  
4、接入llm的思维&指令层。  
5、可以由车万女仆的llm宏观调配（之所以接入llm和车万女仆的不同，有很多原因，但主要还是我的问题）  
程序大致分为几层：  
最下层执行层，把可执行的动作作为次下层动作层的单位元。  
次下层动作层，有根据具体物品、物品状态决定激活内容的功能。其中每个动作对应一个语义向量。  
中间层：状态空间，也就是我称为弹簧空间的部分。空间内有一个点，由其上层决策层传来决策语义作为该点的位移变量。该点的工作原理就是根据位置检索相应的（也就是最近的）动作对应的语义向量，动作被执行后，点的坐标就将减去对应语义向量并执行动作。循环往复。  
决策层：jev根据感知层的内容决策几个值，合并为决策的语义向量传入中间层。  
感知层：就是获得周围信息之类的。  
思维&指令层：让一个llm宏观调控这个体系，顺便能根据输入内容下指令。指令就是一些管理女仆该模式行为的指令。  
最后一层可以被女仆llm调用，同时做了一些相应的提示词工程什么的。
